# 老人健走 App
本專案是一款以 Flutter 開發的行動應用程式，專為長者設計，目標是鼓勵規律健走，並透過簡單清晰的介面，協助記錄步數與健走情況，進而促進健康生活。

## 功能特色
* 步數紀錄：自動記錄每日步數，方便追蹤運動量。
* 距離與時間追蹤：顯示每次健走的距離與持續時間。
* 提醒功能：可設定健走提醒，避免久坐不動。
* 簡單介面：針對長者設計，直覺易用。
* 歷史紀錄查詢：可瀏覽一週或一個月的健走紀錄，追蹤進步情況。
## 技術細節
* 框架：Flutter
* 程式語言：Dart
* 支援平台：Android
* 資料儲存：Firebase
## 安裝方式
1. 確認已安裝 Flutter 與相關環境。
2. Clone 專案：
~~~
git clone https://github.com/Erick930107/Elder_Jogging_app.git
cd elder-walking-app
~~~
3. 安裝相依套件：
~~~
flutter pub get
~~~
4. 執行專案：
~~~
flutter run
~~~
## 使用說明
1. 開啟 App 後，首頁會顯示當前步數與今日健走時間。
2. 可進入「運動紀錄」檢視過去一週或一個月的運動數據。
3. 進入「運動」可開始計時和記步運動。
4. 可進入「影片」觀看和學習正確運動姿勢。
5. 主頁面會顯示當前天氣，並告知是否適合戶外運動。
